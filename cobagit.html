Pengertian Git

Git adalah sistem kontrol versi yang dipakai untuk mencatat dan mengelola perubahan kode dari waktu ke waktu.

Fungsi Git

Git memiliki beberapa fungsi, diantaranya:

  • Menyimpan versi kode program
  • Memudahkan kolaborasi antar developer
  • Membantu mengelola proyek perangkat lunak
